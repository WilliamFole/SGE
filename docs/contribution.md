Como contribuir

1. Abrir uma issue descrevendo o problema ou melhoria desejada.
2. Criar uma branch com nome descritivo (ex: feature/novo-relatorio).
3. Escrever testes quando aplicável e atualizar a documentação.
4. Submeter um pull request com descrição clara e passos para reproduzir.

Boas práticas
- Manter comentários e docstrings em Português (pt-PT) quando o texto
  for dirigido aos utilizadores/administradores. Mensagens técnicas podem
  ficar em inglês quando mais apropriado para a comunidade.
- Incluir changelog/resumo nas PRs para facilitar revisão.

Contato
- Para questões urgentes contacte o mantenedor principal (informações no
  repositório ou no ficheiro de suporte).
